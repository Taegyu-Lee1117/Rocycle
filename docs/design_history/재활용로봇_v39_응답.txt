 2. x=312.9 재마킹 — 왜 안 했고, 뭘로 대체됐는가
====================================================================

**[해소] 재마킹 자체는 실행하지 않았다.** 대신 4일차에 벨트 위
서로 다른 여러 실제 지점에서 실물 파지를 반복 성공시켰다:

```
종이박스   x≈208mm
건전지     x≈292~303mm (여러 번 재시도 끝에 성공)
PET병      x≈458mm
캔(근거리) x≈372mm, (원거리) x≈600mm
```

**[추론] 이건 "8.62mm 국소 이상치가 실재하지 않는다"를 증명한
게 아니다** — 정적 펜 마킹 1점보다 "실제 파지가 되는가"라는
더 직접적인 기준으로 4~5개 지점을 검증했다는 뜻이다. 벨트
길이 방향 전역에서 좌표 정확도가 실사용 목적에는 충분하다는
근거가 되지만, 원래 우려(국소 왜곡의 정체)를 정밀하게 규명한
건 아니다. **필요하면 x=312.9 재마킹은 여전히 유효한 다음
작업이다** — 지금은 우선순위가 낮아졌을 뿐이다.

 3. can/건전지 파지력·좌표 — 실측 결과
====================================================================

### 3-1. can

- **좌표**: 벨트 여러 위치에서 반복 성공(위 2절). 벨트 먼 쪽
  (x>590mm 부근)은 일반적인 수직 자세로 도달 불가능한 지점이
  있었고, 티치펜던트로 직접 찾은 자세(x=599.76, y=-262.97,
  z=316.68, rx=2.45, ry=161.14, rz=-84.84 — 일반 자세 대비 rz가
  약 175° 다름)로 해결. **[교훈] 도달 불가 지점에서 자세를
  조정할 때 ry만 스캔하지 말고 rz도 함께 바꿔볼 것** — 이번엔
  ry만 돌려서는 전혀 안 됐는데 rz까지 크게 바꾸니 바로 도달됨.
- **파지력**: 기본값(약 40N)으로 닫으면 찌그러짐, **5N으로
  낮추면 찌그러짐 없이 안정적으로 파지됨**을 확인. **[과대 청구
  금지]** 정확한 찌그러짐 임계값(상한) 자체를 특정한 건 아니다
  — 40N과 5N 사이 어딘가에 실제 한계가 있다는 것만 안다.

### 3-2. battery (AA)

- **[팀결정 — 4일차] AA 유지, D형 전환 불필요.** 오늘 여러 차례
  시행착오 끝에(아래 5절 참고) 정확한 좌표/깊이 조합을 찾아
  실제 파지 성공, battery_bin까지 이동 완료.
- 깊이는 병/캔(100mm)과 다르게 **110mm**가 정확한 값이었음
  (호버 z=430 기준).

 4. 통 티칭 완료 — 5개 전부
====================================================================

paper/plastic/can/battery/review 5개 통 전부 호버+PLACE 좌표
확정, `config/bin_teach_points.py`에 기록. 과정에서 새로 발견한
문제 4가지:

1. 로봇이 벨트 먼 쪽 물체로 이동할 때 **로봇 베이스/몸통이
   회전하며 통 자체를 밀어버리는 충돌** — `obstacles.py`는
   엔드이펙터 목표점만 검사해서 이런 몸통 충돌은 못 잡음. 통
   5개를 로봇에서 먼 방향으로 총 9cm 물리 이동시켜 해결.
2. **CAN·BATTERY 통 위치는 일반 수직 자세로 도달 불가능** —
   CAN은 손목을 기울여(ry=166) 해결, BATTERY는 통을 옮기거나
   기울이지 않고 목표 대비 xy 각 13mm/11mm 부족한 지점을 그대로
   채택(통이 넓어 문제 없음을 확인).
3. **`MoveLine`의 직선 보간은 시작·끝점이 각각 도달 가능해도
   그 사이 전체 경로가 관절한계 안에 있어야 성공한다** — 아니면
   `success=True`를 반환하면서 로봇이 전혀 안 움직인다. 자세가
   크게 바뀌는 이동에서 반복 재현. 대응: 중간 경유점으로 나누고
   매번 `get_current_posx()`로 실제 이동 여부 확인.
4. **통 PLACE 높이(낮은 z)에서 상승 없이 바로 다음 통으로
   이동하면 그리퍼가 통을 밀어버리는 사고가 실제로 재현됨** —
   반드시 "수직 상승 → 수평 이동 → 수직 하강" 3단계 시퀀스 준수.

====================================================================
 5. 다중 물체 테스트 — 새로 발견한 것들
====================================================================

벨트에 PET병/캔/종이박스/건전지 4종을 동시에 올려두고 순서대로
집어 각 통에 배치, 전부 성공. 과정에서:

- **그리퍼 'c'(닫기) 명령은 비동기다** — 물리적으로 완전히
  닫히기 전에 반환된다. 닫기 직후 바로 로봇을 움직이면(특히
  상승) 물체를 놓친다. **대응: 닫기 후 최소 1초, 낮춘 힘(5N)
  이면 2초 대기.**
- **파지력 설정은 자동으로 리셋되지 않고 세션 내내 유지된다** —
  캔용으로 낮춘 5N이 이후 건전지에도 그대로 적용되거나, 반대로
  기본값 복원을 잊고 캔을 다시 잡아 찌그러뜨리는 실수가 실제로
  둘 다 재현됨. 매 파지 전 현재 힘 설정이 그 물체에 맞는지
  명시적으로 확인하는 습관이 필요.
- 작은 물체(건전지)는 카메라 기반 좌표 추정 오차가 커서 여러 번
  실패 후, "현재 그리퍼 좌표를 이미지에 역투영해 실제 물체
  픽셀과 직접 비교"하는 방법으로 해결 — 벨트 레일이 Y를
  고정한다는 가정이 이번엔 틀렸던 것으로 드러남(경우에 따라
  다를 수 있음, 매번 가정하지 말 것).
