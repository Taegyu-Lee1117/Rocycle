## 0. 요약
====================================================================

**펜 마킹 방식(v32/v33 결정)으로 벨트 위 3개 지점을 실측한 결과,
전부 8~13cm(!) 오차가 나왔다.** 오전에 테이블 위 2개 지점에서
"육안상 정확"으로 정성 확인했던 재캘리브레이션(12샘플, 회전
다양성 42도로 확대)이, 실제로는 벨트 구간에서 심각하게 부정확
하다는 게 정밀 측정(펜 마킹)으로 처음 드러났다.

====================================================================
## 1. 실측 데이터
====================================================================

체커보드(종이, 10x7, 25mm/칸)를 벨트 위에 직접 테이프로 고정하고,
카메라가 검출한 특정 코너 픽셀 → `pixel_to_base_point`(T_cam2base
+ belt_plane) → 로봇 이동 → 펜으로 그 코너 옆에 마킹 → 실제
코너와 마킹 사이 거리를 자로 측정하는 방식으로 3개 지점 실측:

```
지점       예측 base 좌표(x,y,z)         실측 오차
코너0      (328.89, -267.43, 319.44)      8.7cm
코너9      (464.64, -270.03, 319.93)      12.8cm  (코너0과 같은 행,
                                                    X만 136mm 더 멀리)
코너30     (329.50, -314.86, 319.71)      ~10cm   (코너0과 비슷한 X,
                                                    다른 행 — 벨트
                                                    폭 안(3~6행)임을
                                                    사용자가 직접 확인)
```

**패턴**: 오차가 Y(벨트 폭 방향)보다 X(벨트 길이 방향)에 더
민감하게 반응한다 — 같은 X(코너0≈코너30)는 비슷한 오차, X가
136mm 멀어진 코너9는 오차도 더 커짐(87mm→128mm).

**종이 두께/평탄성 문제는 배제됨**: 코너30은 사용자가 직접 확인한
"벨트 위(3~6행)" 지점인데도 오차가 줄지 않았다 — 종이가 안
평평해서 생기는 오차가 아니라는 뜻이다.

## 2. CLI 가설 [추론, 미검증]
====================================================================

**3일차 재캘리브레이션(12샘플)의 로봇 자세가 전부 Y≈-155~-215
구간(로봇 베이스에 가까운 쪽)에 몰려 있었다.** 벨트는 Y≈-267~
-345로 이 범위 밖(calibration 샘플이 커버하지 못한 extrapolation
영역)이다.

회전 성분에 남아있는 작은 잔차 오차가 있다면, 그 오차가 유발하는
위치 오차는 **카메라로부터의 거리(또는 캘리브레이션 샘플 중심
으로부터의 거리)에 비례해서 커진다** — 캘리브레이션 샘플 근처
(오늘 오전 정성 확인 지점들)에서는 작아서 육안으로 못 잡았고,
벨트(샘플 범위 밖, 더 멀리)에서는 증폭되어 크게 나타났다는 게
현재 가설이다.

**검증 안 된 부분**: 이 가설이 맞다면 오차가 "캘리브레이션 샘플
중심으로부터의 거리"에 대략 비례해야 하는데, 지금 3개 데이터
포인트만으로는 이걸 정량적으로 확인하지 못했다(방향 벡터가 아니라
스칼라 거리만 측정함 — 자로 거리만 재고 방향은 기록 안 함).

====================================================================
## 3. CLI 제안 — 3차 재캘리브레이션
====================================================================

체커보드를 다시 그리퍼에 옮겨 붙이고, **이번엔 로봇 자세(캘리브
레이션 샘플)를 벨트 Y범위(-267~-345)까지 포함**하도록 다시
촬영·계산한다. 회전 다양성(2차 때 이미 해결한 42도 범위)은
유지하면서, **위치 범위도 실제 사용 영역(벨트)을 브래킷(bracket)
하도록** 확장하는 게 핵심 차이다.
