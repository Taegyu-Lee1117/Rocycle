# 요구사항 명세서

**프로젝트명** 컨베이어 기반 재활용 분류 협동로봇
**작성일** 2026-09-10
**문서 버전** 2.0

---

## 1. 문서 개요

### 1-1. 목적

본 문서는 재활용 분류 협동로봇 시스템이 충족해야 하는 기능
요구사항과 비기능 요구사항, 그리고 시스템이 가지는 제약사항을
정의한다.

### 1-2. 범위

컨베이어로 이송되는 재활용품을 인식하고 로봇 팔로 파지하여
분류하는 시스템 전체를 다룬다. 데이터베이스와 웹 화면은 인터페이스
규격까지만 정의하고 상세 구현은 별도 문서에 위임한다.

### 1-3. 용어

| 용어 | 정의 |
|---|---|
| 파지 | 그리퍼로 물체를 집는 동작 |
| 예측 파지 | 이동 중인 물체의 미래 위치를 계산해 파지하는 방식 |
| 핸드오버 | 로봇이 물체를 사람에게 건네주는 동작 |
| 순응 제어 | 외력에 유연하게 반응하도록 로봇 강성을 낮춘 제어 모드 |
| 확인 필요 통 | 로봇이 최종 판단을 내리지 못한 물체를 모으는 통 |
| 도달 한계 | 로봇 팔이 물체를 파지할 수 있는 최대 x 좌표 |

## 2. 시스템 개요

### 2-1. 시스템 목표

**재활용품을 자동으로 분류하되, 로봇이 판단할 수 없는 것은
억지로 처리하지 않는다.**

판단 불가 상황은 세 가지 경로로 처리한다.

```
사람이 처리해야 하는 것    사람에게 직접 건넨다
판단이 불확실한 것         확인 필요 통으로 보낸다
인식되지 않는 것           손대지 않고 흘려보낸다
```

### 2-2. 운영 환경

| 항목 | 사양 |
|---|---|
| 로봇 | 두산 M0609 (컨트롤러 192.168.1.100) |
| 그리퍼 | OnRobot RG2 (192.168.1.1, Modbus TCP 502) |
| 고정 카메라 | Logitech C270 HD, 1280×720, 7.5Hz |
| 손목 카메라 | Intel RealSense D435i, 컬러·깊이 각 15Hz |
| 컨베이어 | Arduino Uno R3 제어, 시리얼 |
| 제어 PC | Intel Core i7-13620H (16스레드), 31GiB, RTX 4060 8GB |
| 운영체제 | Ubuntu 24.04.3 LTS |
| 분류 통 | 5개 |

**네트워크**

```
로봇망   192.168.1.32   로봇 컨트롤러, 그리퍼
사내망   172.24.3.240   화면, 데이터베이스 연동
```

## 3. 기능 요구사항

### FR-01 물체 인식

| 항목 | 내용 |
|---|---|
| 설명 | 컨베이어 위 물체의 종류와 위치를 식별한다 |
| 입력 | 고정 카메라 영상 |
| 출력 | 물체 종류, 화면 좌표, 신뢰도 |
| 인식 대상 | 6종 (캔, 건전지, 종이, 라벨 페트병, 플라스틱, 비닐) |
| 판정 기준 | 신뢰도 0.6 이상만 검출로 인정 |
| 충족 여부 | **충족** |
| 근거 | 실물 검증, 전 품목 신뢰도 0.6 초과 확인 |

### FR-02 좌표 변환

| 항목 | 내용 |
|---|---|
| 설명 | 화면 좌표를 로봇 작업 좌표로 변환한다 |
| 방식 | 카메라 내부 파라미터 + 벨트 평면 교차 + 경험적 보정 |
| 정확도 요구 | 그리퍼 개폐폭(110mm) 대비 충분한 여유 |
| 충족 여부 | **충족** |
| 근거 | RMS 4.5mm, 최대 8.6mm |

### FR-03 이동 물체 추적

| 항목 | 내용 |
|---|---|
| 설명 | 컨베이어로 이동하는 물체를 프레임 간 연속 추적한다 |
| 방식 | 칼만 필터 기반 위치·속도 추정 |
| 확정 조건 | 연속 9프레임 동일 클래스 검출 |
| 동시 추적 | 최대 3개 |
| 충족 여부 | **충족** |
| 근거 | 순차 처리 실물 검증 완료 |

### FR-04 예측 파지

| 항목 | 내용 |
|---|---|
| 설명 | 이동 중인 물체를 정지시키지 않고 파지한다 |
| 방식 | 로봇 도달 시점의 물체 위치를 예측해 그 지점으로 이동 |
| 예측 구간 | 준비 동작 + 이동 시간 + 하강 시간 |
| 충족 여부 | **충족** |
| 근거 | 7종 완주 시험 파지 실패 0건 |

### FR-05 물체별 파지 조건 적용

| 항목 | 내용 |
|---|---|
| 설명 | 물체 종류에 따라 파지력·대기 시간·하강 깊이를 달리한다 |
| 근거 | 캔은 과도한 파지력에 변형되고, 무거운 물체는 약한 힘에 미끄러짐 |
| 충족 여부 | **충족** |
| 근거 | 품목별 실측 후 설정 파일로 외부화 |

### FR-06 무게 기반 내용물 판별

| 항목 | 내용 |
|---|---|
| 설명 | 파지한 물체의 무게를 측정해 내용물 유무를 판별한다 |
| 방식 | 파지 전후 힘 센서 값의 차이 |
| 임계값 | 0.20kg |
| 적용 대상 | 캔, 라벨 페트병 |
| 충족 여부 | **충족** |
| 근거 | 빈 캔 +44.3g / 내용물 캔 +494.2g 구분 확인 |

### FR-07 사람에게 전달

| 항목 | 내용 |
|---|---|
| 설명 | 사람의 처리가 필요한 물체를 직접 건넨다 |
| 대상 | 라벨 붙은 페트병 (라벨 제거 필요) |
| 방식 | 제시 자세 이동 후 순응 제어 전환, 당김 감지 시 개방 |
| 감지 조건 | 수평 속도 3.0mm/s 이상 연속 2회 **그리고** 하향 제외 변위 7mm 이상 |
| 미수령 처리 | 15초 경과 시 확인 필요 통으로 배치 |
| 충족 여부 | **충족** |
| 근거 | 인계 성공 7회, 오탐 개방 0건, 폴백 경로 실물 검증 |

### FR-09 컨베이어 제어

| 항목 | 내용 |
|---|---|

## 4. 비기능 요구사항

### 4-1. 성능

| 항목 | 요구 | 실측 | 충족 |
|---|---|---|---|
| 좌표 정확도 | 그리퍼 여유 내 | RMS 4.5mm | 충족 |
| 사이클 시간 | 명시 없음 | 17~24초 | — |
| 검출 처리율 | 카메라 프레임 대비 | 7.49Hz (카메라 7.5Hz) | 충족 |
| 파지 성공률 | 명시 없음 | 완주 시험 3회 전부 7/7 | — |

**연산 자원 점유 (GPU 전환 완료, 10일차 오후)**

```
                CPU 추론(오전)   GPU 추론(오후, 현재)
검출 노드 CPU    약 44%(7코어)    약 30%(0.3코어)
전체 CPU(us)     45.6%            11.6%
GPU 사용률       0%               5%
VRAM             -                335MiB / 8188MiB
유휴 시 CPU      약 3.1%
메모리           31GiB 중 2.6%
```

**추론은 GPU에서 수행된다(10일차 오후 전환, 실물검증 완료).**
전환으로 CPU 점유가 약 23배 감소(698%→30%). 검출 발행 속도는
7.42→7.49Hz로 거의 그대로인데, 이는 카메라 자체 프레임률
(7.5Hz)이 상한이라 추론이 빨라져도 발행 간격은 카메라에 묶여
있기 때문이다 — 이 덕분에 우려했던 "확정 프레임 수 비례조정"
문제가 발생하지 않았다(아래 4-3, 02번 문서 참고).

### 4-2. 안전

| 항목 | 요구 | 구현 |
|---|---|---|
| 비상 정지 | 즉시 정지 수단 제공 | 물리 버튼 + 화면 버튼 |
| 물체 손실 방지 | 도달 범위 이탈 방지 | 도달 한계 접근 시 컨베이어 정지 |
| 오판정 대응 | 불확실 시 안전측 처리 | 확인 필요 통 라우팅 |
| 사람 전달 안전 | 위험 물체 전달 차단 | 전달 직전 무게 확인 |
| 충돌 방지 | 통·구조물 회피 | 3단계 수직 이동 시퀀스 |

**설계 원칙**: 분류 결과를 안전 게이트로 사용하지 않는다.
사람에게 건네는 판단은 비전이 아닌 물리량(무게)으로 수행한다.

### 4-3. 신뢰성

| 항목 | 요구 | 구현 |
|---|---|---|
| 통신 단절 대응 | 컨베이어 자동 정지 | 워치독 설계 (미검증) |
| 계측 실패 대응 | 안전측 라우팅 | 순 무게 -0.15kg 미만 시 확인 필요 통 |
| 무한 대기 방지 | 시간 제한 | 정지 사유 120초, 핸드오버 15초 |

### 4-4. 유지보수성

| 항목 | 구현 |
|---|---|
| 설정 외부화 | 파지 조건, 라우팅, 좌표, 임계값 전부 설정 파일 |
| 판정 로직 분리 | 코드에 품목명 분기를 두지 않음 |
| 로그 | 판정 근거를 실측값과 함께 기록 |

### 4-5. 확장성

**단일 로봇 구성이며, 다중 로봇 확장 시 필요한 변경은 별도
문서(다중 로봇 확장 설계)에 정의한다.**

## 5. 제약사항

**아래는 설계 단계에서 확인된 물리적·기술적 한계이며, 회피 방안과
함께 명시한다.**

### C-01 투명체 검출 불가

| 항목 | 내용 |
|---|---|
| 내용 | 고정 카메라에 깊이 정보가 없어 투명한 물체는 배경이 비쳐 검출이 어렵다 |
| 영향 | 무라벨 페트병, 투명 플라스틱 용기 |
| 회피 | 해당 품목을 인식 대상에서 제외. 불투명 물체만 처리 |

### C-02 인식 범위 제한

| 항목 | 내용 |
|---|---|
| 내용 | 학습한 6종만 인식한다 |
| 영향 | 그 외 물체는 처리되지 않는다 |
| 회피 | 미인식 물체는 벨트 끝 일반쓰레기로 이송 (의도된 동작) |

### C-03 분류의 화면 위치 의존성

| 항목 | 내용 |
|---|---|
| 내용 | 일부 물체는 화면상 x 위치에 따라 분류 결과가 달라진다 |
| 실측 | 특정 종이 상자가 경계 좌우에서 서로 다른 클래스로 100% 분류됨 (양쪽 신뢰도 0.92~0.95) |
| 원인 | 미확인. 카메라 원근 또는 왜곡 추정 |
| 회피 | 물체 배치 위치를 고정. 해당 품목은 운영 대상에서 제외 |

### C-04 물체 자세 의존성

| 항목 | 내용 |
|---|---|
| 내용 | 물체가 벨트 진행 방향과 나란하지 않으면 검출되지 않는 경우가 있다 |
| 실측 | 캔 기준 나란한 자세 77/77 검출, 45도 기울임 0/77, 가로지름 1/77 |
| 범위 | 캔에서 확인. 다른 품목은 미확인 |
| 원인 | 학습 데이터의 촬영 자세 편중으로 추정 |
| 회피 | 배치 방향을 고정 |

### C-05 힘 센서 주기 진동

| 항목 | 내용 |
|---|---|
| 내용 | 로드셀에 주기 약 27초, 진폭 약 ±45g의 진동이 존재한다 |
| 영향 | 측정창보다 주기가 길어 평균·중앙값으로 제거 불가 |
| 회피 | 정밀 계량이 아닌 유무 판별로 설계 |
| 운영 규칙 | 판정 대상 물체는 50g 미만 또는 350g 초과만 사용 |

### C-06 무게 기준값의 자세 의존

| 항목 | 내용 |
|---|---|
