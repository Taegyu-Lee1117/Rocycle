# 관제 PC 이관 패키지 — 읽는 순서

이 폴더는 로봇 팔 제어 담당 쪽에서 만든 코드/설정/캘리브레이션
데이터/문서를 관제 PC(STT/TTS 담당 팀원 랩탑)로 옮기기 위해 통째로
모아둔 것입니다.

**[8일차 갱신] `8일차_관제PC_인수인계_UI작업.md`를 가장 먼저
읽으세요** — 관제 화면 UI 작업과 핸드오버 안전 수정(오늘 실물
사고 재현 포함) 등 최신 인수인계 사항이 정리돼 있습니다. 아래
읽는 순서는 그 이전(6~7일차)에 작성된 최초 이관 안내입니다.

## 읽는 순서

1. **`관제PC_이관_인수인계.md`** — 먼저 읽으세요. 시스템 개요, PC
   역할 분담, 반드시 알아야 할 함정들이 정리돼 있습니다.
2. **`이관_패키지_구성.md`** (이 폴더, 신규) — 위 문서 3절("이관
   대상")에서 빈칸으로 남아있던 정확한 파일 경로·패키지 이름·빌드
   /실행 방법을 채운 문서입니다. 실제 세팅 작업은 이 문서를 보고
   진행하세요.
3. **`캘리브레이션_안내.md`** (이 폴더, 신규) — **가장 중요합니다.**
   어떤 파일이 캘리브레이션 데이터인지, 왜 손대면 안 되는지, 물리
   배치 정보를 정리했습니다.
4. **`확인_체크리스트.md`** (이 폴더, 신규) — 세팅 후 "제대로
   옮겨졌는가"를 단계별로 확인하는 체크리스트입니다.
5. **`CLAUDE.md`** — 현재 확정값과 지켜야 할 원칙(질문이 생기면
   여기부터 검색).
6. **`실측기록.md`** — 일자별 실측 데이터와 경위("이 값이 왜
   이런가"의 답이 대부분 여기 있습니다).
7. **`재활용로봇_설계문서_v32.txt`** — 전체 설계(최신본).

## 폴더 구성

```
handover_to_control_pc/
├── README.md                       (이 파일)
├── 관제PC_이관_인수인계.md          팀원 AI가 원래 작성
├── 이관_패키지_구성.md              신규 — 3절 빈칸 채움
├── 캘리브레이션_안내.md             신규 — 가장 중요
├── 확인_체크리스트.md               신규 — 세팅 후 검증
├── CLAUDE.md
├── 실측기록.md
├── 재활용로봇_설계문서_v32.txt
├── rocycle_robot/                  ROS2 패키지 전체 (소스 그대로 복사)
├── team_share_yolo12s/             YOLO12s 모델 + 검출 래퍼
└── setup_photos/                   물리 배치 참고 사진(1장, 아래 참고)
```

**주의**: `setup_photos/`에는 사진이 1장뿐입니다 — 정식으로 배치를
촬영한 것이 아니라, 고정 카메라가 찍은 프레임 중 로봇·벨트·통이
잘 보이는 것을 하나 골라둔 것입니다. 카메라 설치 각도나 정확한
치수는 사진만으로 알 수 없으니, 실제로 옮길 때는 로봇 팔 제어
담당과 화상으로 확인하며 맞추는 것을 권합니다.
