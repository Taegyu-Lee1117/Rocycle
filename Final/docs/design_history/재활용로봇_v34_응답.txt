 1. 요청1-(1) — 체커보드 종류/두께 확인
====================================================================

**확인 결과: 종이입니다.** 오늘 캘리브레이션·end-to-end 검증에
쓴 체커보드는 판에 붙은 게 아니라 **얇은 종이 인쇄물**입니다 —
벨트 밖으로 걸쳤을 때 처지는 걸(체커보드 마운팅 가이드 과정에서
"종이가 좀 처졌다"는 관측) 직접 확인했으므로 확실합니다.

**두께 영향 재계산**: 일반 프린터 용지 약 0.1mm 기준으로
`오차 ≈ 두께/tan(각도)` 식(1-1절 예시값 역산으로 확인한 식)을
적용하면:
```
30도: 0.1mm / tan(30°) ≈ 0.17mm
40도: 0.1mm / tan(40°) ≈ 0.12mm
```
**둘 다 무시 가능한 수준**(오늘 예정된 측정 정밀도, mm 단위
대비 1/10 이하)입니다.

**결론**: (1) 오늘 캘리브레이션·정성적 e2e 결과는 재검토 불필요
— 종이라 두께 영향이 애초에 무시할 수준이었습니다. (2) 앞으로
펜 마킹 측정에서도 **별도 두께 보정 계산 없이 (a)안(종이를 벨트에
직접 붙임)만 지키면 충분**합니다 — 이미 종이라 바로 적용
가능합니다.

 2. 요청1-(2) / 3절 — 통 PLACE 예외: (a)안 채택
====================================================================

**(a)안(통마다 z_floor = 통 바닥 높이)을 그대로 채택합니다.**
반론 없습니다 — 기존 규칙(z_floor 하나만 두는 단순화) 틀 안에서
처리되고, 어차피 통 티칭 시 재는 값입니다. "통 벽 충돌은 못
막는다"는 한계도 "수직 접근만 쓴다"는 기존 전제 안에서 수용
가능하다는 판단에 동의합니다.

`config/obstacles.yaml`/설계문서 9절 주석을 "통 상단 높이"에서
**"통 바닥 높이"**로 정정했습니다 — 이전 라운드(v32/v33 응답)에서
제가 "통 상단 높이"라고 잘못 표기했던 걸 이번에 바로잡았습니다.
D절 체크리스트도 같이 수정했습니다.

 3. 요청3 — 반대 의견 답변
====================================================================

**(1) 종이 인쇄 체커보드로 바꾸면 코너 검출 정확도가 떨어지는가
— [해당 없음]** 바꾸는 게 아니라 **원래부터 종이**였습니다(1절).
전환 자체가 없으니 정확도 저하 우려도 없습니다.

**(2) 파지 테스트를 먼저 하는 게 실제로 시간을 아끼는가 — [반론,
펜 마킹을 먼저 하겠습니다.]** 지적하신 우려(실패 시 원인 분리가
더 오래 걸린다)에 동의합니다. 게다가 **오늘 실제로 겪은 일이
정확히 이 시나리오입니다** — 1차 캘리브레이션이 157mm나 틀렸는데,
좌표만 따로 떼어 보는 테스트(정성적으로나마)를 했으니 원인을
"캘리브레이션 문제"로 빠르게 특정할 수 있었습니다. 만약 처음부터
건전지로 파지 테스트를 했다면 "안 잡힌다"까지만 알고 좌표/파지력/
접근각도/미끄러짐 중 어디가 문제인지 훨씬 오래 헤맸을 겁니다.
**펜 마킹 준비는 이미 끝나 있어(체커보드 재사용, obstacles 완료,
z_floor 방식까지 확정) 실행 비용도 낮습니다** — 추가 준비 없이
로봇만 풀리면 바로 시작 가능합니다. 이 두 가지(오늘의 실증 사례
+ 낮은 실행 비용)를 근거로 **펜 마킹을 먼저, 파지 테스트는 그
다음**으로 순서를 정합니다.

**(3) 3-3절 (a)안이 적절한가 — [동의, 반론 없음.]** 위 2절 참고.

 5. 순서 (요청4 반영)
====================================================================

```
내일 통 도착 → 3절 (a)안 방식으로 z_floor(통 바닥 높이) 포함해
              티칭 진행

로봇이 풀리는 대로 →
  1. 책상에서 펜 z-오프셋 확정 (ROS2 자동제어, 소폭 상대이동)
  2. 180도 회전 이중 마킹으로 정렬 검증
  3. 종이 체커보드를 벨트에 직접 붙여 6~9지점 측정
  4. (펜 마킹 통과 시) 건전지부터 파지 테스트로 넘어감 —
     실패 시 그때 추가 펜 마킹으로 원인 재분리
```
